# IPTV плейлисты

Проект содержит ссылки из плейлистов, которые были найдены в открытых источниках. Плейлисты составляются преимущественно для граждан РФ и Беларуси.

В других плеерах действия похожи: нужно найти пункт «Добавить URL» или «Открыть сетевой адрес».

> **Важно:** Сторонние программы и значки использовать не получится, так как плейлист привязан к `https://iptvx.one/EPG`, где уже имеются и значки, и программа с описанием просматриваемого материала.
>
> Некоторые каналы могут не работать в вашем регионе, у вашего провайдера или на вашем плеере. Всё относительно.

[Наше сообщество ВКонтакте](https://vk.com/iptvru250) Новости и изменения в плейлистах.

## Плейлисты

### Основной

```
https://raw.githubusercontent.com/NelikKKL/IPTVru/refs/heads/gh-pages/IPTVru.m3u
```

- Для всех плееров: `https://raw.githubusercontent.com/NelikKKL/IPTVru/refs/heads/gh-pages/IPTVru.m3u`.

Плейлист формируется после добавления и проверки ссылок на потоки из тестового плейлиста. Используется полный EPG файл (значки, программа и описание). Пулреквесты не принимаются.

### Стабильный

```
https://nelikkkl.github.io/IPTVru//IPTVstable.m3u8
```

- Для всех плееров:`https://raw.githubusercontent.com/NelikKKL/IPTVru/refs/heads/gh-pages/IPTVstable.m3u8`.

Плейлист формируется после удаления нестабильных и / или неработающих потоков из основного плейлиста. Используется облегченный EPG файл (значки и программа). Пулреквесты не принимаются.

### Мировой

```
https://nelikkkl.github.io/IPTVru//IPTVmir.m3u8
```

- Для всех плееров: `https://raw.githubusercontent.com/nelikkkl/IPTVru/refs/heads/gh-pages/IPTVmir.m3u8`.

Включает в себя зарубежные каналы (никем не поддерживается, обновляется скриптами).

## Юридическая информация

В этом репозитории не хранятся видеофайлы. Репозиторий содержит только ссылки на общедоступные URL-адреса видеопотоков, которые, насколько нам известно, были намеренно опубликованы владельцами авторских прав.

Если какие-либо ссылки в этих плейлистах нарушают ваши права как владельца авторских прав, их можно удалить, отправив запрос на pull request или написав об этом в issue. Однако обратите внимание, что мы не контролируем место назначения ссылки, и простое удаление ссылки из плейлиста не приведет к удалению ее содержимого из Интернета.

Обратите внимание, что ссылка напрямую не нарушает авторские права, поскольку на сайте, предоставляющем ссылку, не создаётся копия. Чтобы удалить этот контент из Интернета, вам следует связаться с веб-хостингом, на котором фактически размещён контент (не с GitHub и не с разработчиками этого репозитория).
